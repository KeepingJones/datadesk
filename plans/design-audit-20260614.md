## Fixes Shipped (7 commits)

### F1 — Button sizing standard (commit `6e3db95`)
Added global button rule: `min-height: 28px; padding: 4px 10px; border-radius: 4px; font-size: 13px`. All daemon Start/Stop buttons and maintenance buttons now meet a consistent 28px minimum touch target.

### F2 — Danger button class for LIVE actions (commit `856da98`)
Added `.danger` CSS class with `border-color: var(--red); color: var(--red)` and a red wash hover state `rgba(248,81,73,0.12)`. Applied to both "Switch to LIVE" buttons (Alpaca panel, T212 panel). These are now visually distinct from all other actions — a misclick is no longer silent.

### F3 — Heading hierarchy (commit `a15369a`)
Fixed inverted size relationship: `.panel h2` raised from 12px → 13px; `.panel h4` added at 12px. Section headers now correctly outrank sub-labels.

### F4 — P&L table scroll cap (commit `325791f`)
Wrapped Daily/Weekly/Monthly P&L tables in `<div style="max-height:280px;overflow-y:auto;">`. History no longer causes the panel to grow unbounded.

### F5 — Qty precision (commit `04b5187`)
Changed position Qty cell from raw `p.qty` to `parseFloat(p.qty).toLocaleString(undefined, {maximumFractionDigits: 4})`. Output: `686.9799` not `686.979907911`.

### F6 — P&L sign display (commit `369a342`)
Fixed the "+$-0" bug. Separated sign logic: `pnlSign = _pnlDollar > 0 ? '+' : ''` (empty for zero/negative), then rendered `Math.abs(_pnlDollar)` with locale formatting. Zero now shows `$0.00 (0%)` not `+$-0`.

### F7 — Focus-visible rings (commit `1711ea7`)
Added `focus-visible` outline rules for `input[type="text"]`, `button`, and `.tab-btn`. Keyboard navigation now shows a clear 2px `var(--accent)` ring.
